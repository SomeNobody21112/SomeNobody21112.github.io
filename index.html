ICHNOVA

Blind signal analysis & decoding

Decodes a raw radio capture with no known settings: estimates carrier offset, symbol rate, modulation and phase, then brute-forces every FEC + interleaver combo and returns a result only if it's statistically significant. Verified on real WWV, WWVB, DCF77, MSF, JJY time signals.

  • NumPy
  • SciPy
  • Viterbi
  • React 19
  • Docker
